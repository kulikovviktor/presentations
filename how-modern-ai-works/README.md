# Как работает современный ИИ — просто

**Описание.** Простая презентация из 7 слайдов, объясняющая работу современных фронтир-моделей ИИ через аналогии с офисом и командой специалистов. Без сложных терминов, с простыми SVG-схемами.

**Аудитория.** Люди вне IT, без технической подготовки, которые хотят понять, как устроены ChatGPT, Grok, Claude и подобные модели.

**Заказчик.** Виктор Куликов ([@kulikovviktor](https://github.com/kulikovviktor)).

**Собрано.** Grok 4.7 (`grok-4.7`).

**Дата.** 2026-10-16.

**Версия.** 1.0.0.

## Как открыть

Открыть `index.html` в любом браузере. Листать стрелками клавиатуры (← → или пробел), кнопками «Назад»/«Дальше» или свайпом (на мобильных).

## Содержание

1. Введение
2. Большой офис (аналогия)
3. Текст в карточки (токены)
4. Внимание (attention)
5. Выборочный вызов специалистов (MoE)
6. Как учится
7. Итог

## Источники

Внешние источники не использовались. Объяснение основано на общеизвестных принципах архитектуры современных LLM (трансформеры, Mixture of Experts).
