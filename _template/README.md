# Название презентации

**Описание.** 2–4 предложения: о чём презентация, сколько слайдов, из чего состоит.

**Аудитория.** Для кого сделано и какой уровень подготовки предполагается.

**Заказчик.** Имя ([@github-логин](https://github.com/github-логин)).

**Собрано.** Агент или продукт, идентификатор модели в обратных кавычках. Пример: Codex, идентификатор модели `gpt-5-codex`.

**Дата.** ГГГГ-ММ-ДД.

**Версия.** 1.0.0.
