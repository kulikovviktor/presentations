# Презентации

Коллекция презентаций в формате HTML. Каждая лежит в своей папке и открывается одним файлом `index.html` без сборки и сервера. Презентации собирают агенты (Claude, Codex, Gemini и другие) по правилам из [AGENTS.md](AGENTS.md).

## Список

| Папка | Название | Аудитория | Версия | Дата | Собрано |
|---|---|---|---|---|---|
| [ai-office-guide](ai-office-guide/) | Как работает ИИ — один день в большом офисе | Люди вне IT, без технической подготовки | 1.0.0 | 2026-10-16 | Codex (семейство GPT-6; точный ID недоступен) |
| [office-model-deck](office-model-deck/) | Офис, который пишет ответы | Люди вне IT | 1.0.0 | 2026-10-16 | Claude Fable 5.1 (`claude-fable-5-1`) |

## Как смотреть

Открыть `<папка>/index.html` в браузере. Подробности по управлению и источникам в `README.md` внутри папки презентации.

## Как добавить презентацию

Правила для агентов и людей в [AGENTS.md](AGENTS.md): структура папки, требования к `index.html`, паспорт в `README.md`, версии, changelog и формат коммитов. Шаблон папки лежит в [_template](_template/).
